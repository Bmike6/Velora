# Velora
Velora is a custom tool that allows roblox developers to have a higher level of tween control on objects.
Which is all coupled into one single module script having its own prefabs and dependecies within the structure.
The only external code that was taken is the EasingStyle functions which came from this Dev Forum: https://devforum.roblox.com/t/easing-functions-cheat-sheet/2224295
Please note this class does handle all GC, but is still responsible on you of releasing any references to a velora object.
As this is not tween service.


# Features
  Yielding, 
  Pausing, 
  Multi Object Computation, 
  4 different callbacks for scenarios, 
  Custom Easing Styles, 
  Looped Veloras, 
  Model Applications, 
  Strict Type Check


# Use
Velora is very simple to use all you need to do is download the Velora module and read on the example file
Velora was designed to be highly abstracted so you the client do not have to worry about much but just getting
your instances from point A to point B with any easing style you want.
